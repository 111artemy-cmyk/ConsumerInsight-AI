# Technical Report: ConsumerInsight-AI

> *A Hybrid Framework Combining LLM and Marketing Analytics for Automated Consumer Insights and Campaign Generation.*

**Author**: Xintong Wang
**Project Type**: Cross-disciplinary Portfolio Project
**Target Programme**: Master of Science in Data Science — AI Track / Marketing Analytics Track, University of Macau
**Last Updated**: September 2026

---

## 1. Abstract

The rapid growth of user-generated content on Chinese social-commerce
platforms (小红书, 微博, 天猫) has created an enormous but largely
unstructured stream of consumer voice. Traditional marketing analytics
treats this stream as survey responses, requiring manual coding and
expensive panel research. Meanwhile, recent Large Language Models (LLMs)
excel at extracting structured insights from free text but rarely produce
**decision-grade** artefacts that marketers can act on directly.

This project proposes **ConsumerInsight-AI**, a hybrid framework that:

1. Routes social-commerce reviews through a **multi-aspect sentiment
   analysis** layer that returns interpretable scores on six dimensions
   (product quality, value-for-money, packaging design, skin feel,
   long-wear, service experience).
2. Combines **LLM topic extraction** with **classical TF-IDF keyword
   validation** to identify the dominant themes customers talk about.
3. Couples **TF-IDF + KMeans clustering** with **LLM persona
   synthesis** to produce four consumer personas that map directly to
   campaign targeting.
4. Builds a **soft marketing funnel** from review signals and trains
   a **Ridge regression** to estimate ROI per audience segment.
5. Generates **multi-channel campaign copy** for each persona with
   predicted click-through rates and channel-level budget allocation.

A **pluggable LLM backend** (Mock / OpenAI-compatible) keeps the entire
pipeline reproducible without paid APIs, making it suitable as a
teaching artefact and a graduate-school portfolio submission.

## 2. Motivation

Two trends motivate this work:

* **From surveys to social listening.** Marketing teams increasingly
  rely on social-media scraping rather than traditional surveys because
  the former is faster, cheaper, and reflects organic consumer voice.
  However, social-media text is noisy, multi-topic, and emotionally
  mixed — survey-grade coding tools are not designed for it.
* **From generic LLMs to decision artefacts.** Off-the-shelf LLMs can
  summarise reviews but rarely produce the *artefacts* marketers need
  (personas, funnel drops, ROI by segment, multi-channel copy
  variants). This project closes that gap by combining LLM outputs with
  classical analytics into a single, reproducible pipeline.

The dual-track *AI / Marketing Analytics* specialisation in UM's MSc
in Data Science is precisely the intersection this project addresses.

## 3. System Architecture

See [`docs/ARCHITECTURE.md`](ARCHITECTURE.md) for the full data-flow
diagram. At a high level, the system is organised as four layers:

```
   ┌─────────────────────────────────────────────────────────┐
   │  Data Layer        synthetic / user-supplied reviews     │
   │  AI Analysis       sentiment / topics / persona / trend  │
   │  Marketing Layer   segmentation / funnel / ROI / copy    │
   │  Presentation      matplotlib charts + Markdown report   │
   └─────────────────────────────────────────────────────────┘
```

Each layer is implemented as an independent Python module so that
reviewers can swap any single component (e.g. the LLM backend, the
clustering algorithm) without touching the rest of the system.

## 4. Methodology

### 4.1 Data

* Default corpus: 1500 synthetic reviews generated by
  :func:`src.data_loader.generate_synthetic_reviews`. The corpus is
  **deterministic** (`RANDOM_SEED=42`) and stratified across four
  user segments (学生党, 通勤族, 成分党, 精致妈妈) and three
  platforms (小红书, 微博, 天猫) with realistic polarity skew
  (~65% positive, 25% neutral, 10% negative).
* Users may replace the corpus by passing a CSV with the columns
  documented in `src/data_loader.py:REQUIRED_COLUMNS`.

### 4.2 Multi-Aspect Sentiment Analysis

* Six pre-defined aspects:
  `product_quality`, `value_for_money`, `packaging_design`,
  `skin_feel`, `long_wear`, `service_experience`.
* The LLM is prompted with the review text and the aspect list, and is
  asked to return JSON of the form
  `{"dimensions": {aspect: {"score": float in [-1, 1], "rationale": str}}, "overall": float}`.
* The Mock LLM uses a lexicon + intensifier/negator rule system to
  produce deterministic, reproducible scores.
* Outputs are aggregated at three levels:
  per-review (long format), per-aspect (means), per-segment (cross-tab).

### 4.3 Topic Extraction

* Prompt the LLM with a sample of up to 120 deduplicated reviews and
  ask for 5 topics, each with:
  `topic_id`, `topic_label_cn`, `description`,
  `representative_keywords` (5), `share_estimate` (in [0,1]).
* Independently run TF-IDF (char n-grams 2–4) to obtain the
  corpus-level top keywords as a cross-check.
* Each review is then assigned to its highest-overlap topic.

### 4.4 Persona Generation

* TF-IDF features (char n-grams) → KMeans with k = 4.
* For each cluster, the 3 documents closest to the centroid are
  extracted as *representative reviews*.
* The LLM is prompted to synthesise a persona card for each cluster
  with the schema:
  `persona_id`, `nickname`, `age_range`, `occupation`,
  `core_need`, `pain_points` (list of 3), `preferred_channels` (list),
  `recommended_campaign_angle`, `sample_message`.

### 4.5 Audience Segmentation & Trend Detection

* `Segmenter` runs KMeans on (TF-IDF + one-hot platform/age + rating)
  to produce 4 segments and a per-segment profile (volume, average
  rating, platform mix, age-band mix, top features).
* `TrendDetector` aggregates per week and computes the **rolling
  linear slope** of `overall` sentiment; weeks are labelled as
  *rising / falling / stable*.

### 4.6 Soft Funnel & ROI

* `FunnelAnalyzer` defines five proxy stages and counts reviews whose
  text contains stage-specific keywords (or whose rating & sentiment
  cross a threshold for "satisfied").
* `ROIPredictor` constructs a `soft_conversion` target as
  `sigmoid(1.0·overall + 0.6·high_rating + 0.3·long_text + 0.2·repurchase_intent)`
  and fits a Ridge regression to obtain interpretable coefficients.
  Per-segment ROI is then computed as
  `(predicted_conversion · ARPU · volume − CAC · volume) / (CAC · volume)`.

### 4.7 Campaign Generation

* For each persona, the LLM produces `n_variants_per_persona`
  candidates across the persona's preferred channels, with fields
  `headline`, `body`, `hashtags`, `predicted_ctr`, `rationale`.
* Budget share per channel is computed as the average predicted CTR
  normalised to 1.

## 5. Evaluation

The pipeline ships with a **Mock LLM** for offline reproducibility and
an optional **OpenAI-compatible backend** for higher-fidelity results.
We evaluate the framework from three angles:

| Dimension              | Mock LLM                                  | OpenAI-compatible LLM               |
|------------------------|-------------------------------------------|--------------------------------------|
| Reproducibility        | 100% deterministic                        | Stochastic (set `temperature`)       |
| Cost                   | Free, offline                             | Pay-per-token                        |
| Sentiment accuracy     | Lexicon-based; works well for polar words | Context-aware; handles sarcasm better |
| Topic coherence        | Heuristic + keyword overlap               | Better semantic abstraction          |
| Persona richness       | Template-based, four fixed cards          | Free-form, higher diversity          |

For admission-portfolio purposes, the **Mock LLM run is fully
reproducible** and demonstrates that the engineering scaffolding is
correct. Replacing the backend is a one-line environment change.

## 6. Limitations & Future Work

* **Synthetic data.** The shipped corpus is synthetic; production
  deployment would require scraping real reviews (e.g. via Selenium or
  the platforms' open APIs) and applying the same cleaning pipeline.
* **Soft funnel.** In the absence of impression/click logs, the funnel
  is constructed from review text. Future work would integrate ad-side
  data (曝光 / 点击 / 转化) and use **causal / uplift models**.
* **ROI model.** The Ridge model is illustrative; a production version
  would use **Bayesian hierarchical models** or **transformer-based
  uplift** and calibrate against real revenue.
* **Persona validation.** Personas are LLM-synthesised; validating them
  against downstream A/B test lift is left as future work.

## 7. Conclusion

`ConsumerInsight-AI` demonstrates that **LLMs and classical marketing
analytics are complementary, not competing**. The framework turns raw
social-commerce text into decision artefacts (segmented personas,
funnel diagnostics, ROI estimates, multi-channel copy) that bridge the
gap between academic ML and the day-to-day practice of growth
marketing. It is a concrete piece of evidence that the author can work
across both the **AI** and the **Marketing Analytics** dimensions of
UM's MSc in Data Science.
